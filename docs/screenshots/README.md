# Знімки екрана для пояснювальної записки

Зробіть знімки на фізичному iPhone, коли застосунок завантажено в Expo Go. Для демонстрації використайте власну тестову річ або демо-записи. Уникайте особистих даних і реальних документів у кадрі.

| Ім’я файла | Що показати |
| --- | --- |
| `01-overview.png` | Лічильники і список останніх доданих речей. |
| `02-item-form.png` | Заповнену форму додавання речі та вибрану категорію. |
| `03-catalog-filter.png` | Пошук «ЛІХ» разом із вибраною категорією «Інструменти». |
| `04-item-details.png` | Картку з фото, місцем зберігання і датою. |
| `05-category-blocked.png` | Вимкнену дію видалення категорії з причиною. |
| `06-dark.png` | «Каталог» або «Огляд» після вибору «Дані → Вигляд → Темна». |
| `07-camera-result.png` | Форму з попереднім переглядом щойно зробленого фото. |
| `08-favorites.png` | «Обране» з позначеними тестовими записами. |
| `09-backup.png` | Вкладку «Дані» або підтвердження відновлення тестового каталогу. |
| `10-appearance.png` | «Дані → Вигляд» з трьома режимами та позначкою вибраного. |

Спосіб знімання на iPhone з Face ID — одночасно натиснути бічну кнопку й кнопку збільшення гучності. Додайте отримані PNG до цієї папки та вставте потрібні зображення у додаток Б. Знімки екрана внесіть до записки після перевірки на телефоні.
