# Особисті речі

Мобільний застосунок для обліку особистих речей та пошуку за категоріями. Комплексна курсова робота ХНТУ, 2026. Каталог і фото зберігаються на iPhone. Для роботи з відкритим каталогом інтернет не потрібен.

## Запуск на iPhone з Windows

Потрібні Git, Node.js 22.13+ у гілці 22 (перевірено на 22.23.4), npm і [Expo Go для SDK 58](https://apps.apple.com/ua/app/expo-go/id982107779). Xcode і Mac не потрібні.

```powershell
git clone https://github.com/Sh1kami/Kursovoj.git
cd Kursovoj
npm ci
npx expo login
npm start
```

1. У Expo Go на iPhone увійдіть у той самий обліковий запис Expo, що й у терміналі. Вхід потрібен середовищу Expo Go. У каталозі реєстрації немає. [Вимога Expo Go для iOS](https://expo.dev/changelog/expo-go-57-login)
2. Під’єднайте ПК та iPhone до однієї мережі Wi-Fi. Відскануйте QR-код системною камерою iPhone і відкрийте посилання в Expo Go.
3. Якщо мережа блокує пряме підключення, зупиніть Metro через Ctrl+C і виконайте `npm run start:tunnel`. Відскануйте новий QR-код. У SDK 58 тунель використовує обліковий запис Expo і потребує інтернету. [Документація SDK 58](https://expo.dev/changelog/sdk-58#a-faster-more-reliable-expo-cli-tunnel)

| Симптом | Що перевірити |
| --- | --- |
| Expo Go повідомляє про несумісну версію | Оновіть Expo Go до випуску з підтримкою SDK 58. |
| Після сканування запитується вхід | Виконайте `npx expo whoami` і звірте обліковий запис з Expo Go. |
| iPhone не бачить Metro через Wi-Fi | Дозвольте Expo Go доступ до локальної мережі в iOS, перевірте дозвіл Node.js у брандмауері Windows для приватної мережі або використайте тунель. |
| Metro не оновив код | Зупиніть сервер і виконайте `npm start -- --clear`. |
| Галерея не відкривається | Перевірте доступ до фото в налаштуваннях iPhone. Запис можна зберегти без фото. |

## Функції

- **Огляд** показує кількість речей і категорій та п’ять останніх записів.
- **Каталог** дозволяє шукати за частиною назви. Регістр українських літер не впливає на результат. Пошук і фільтр за категорією працюють одночасно.
- **Картка речі** містить назву, категорію, дату додавання та необов’язкові місце, опис і фото. Доступні редагування і видалення з підтвердженням.
- **Категорії** можна створювати, перейменовувати й видаляти. Поки категорія має пов’язані речі, видалення заблоковане.
- **Додати демо-дані…** на вкладці «Огляд» після підтвердження створює до чотирьох записів із позначкою «Демо». Повторний запуск пропускає збережені записи з такими назвами.

## Структура і перевірки

| Шлях | Призначення |
| --- | --- |
| `App.tsx`, `index.ts`, `app.json` | Запуск Expo та навігація |
| `src/screens/`, `src/components/`, `src/theme.ts` | Екрани, спільні компоненти і системна тема |
| `src/hooks/useInventory.ts`, `src/domain.ts`, `src/types.ts` | Стан даних, валідація, пошук і типи |
| `src/database/`, `src/photos.ts` | SQLite, міграція, CRUD і копії фото |
| `tests/`, `docs/` | Автоматичні тести, діаграми та інструкції |

У SQLite таблиця `categories(id, name, name_key)` має унікальний ключ нормалізованої назви. Таблиця `items(id, name, category_id, description, location, photo_name, created_at)` посилається на категорію через зовнішній ключ з `ON DELETE RESTRICT`. [Докладна схема та ERD](docs/database.md)

```powershell
npm run typecheck
npm run lint
npm test
npx expo-doctor
npm run build:ios
```

`npm test` перевіряє доменну логіку й запускає той самий SQL на SQLite, доступному в Node.js. `build:ios` експортує JavaScript-бандл для iOS. [Тест-план і результати](docs/test-plan.md)

## Сценарій захисту на 3–5 хвилин

1. **0:00–0:45.** Відкрийте застосунок через Expo Go. Покажіть «Огляд» і коротко поясніть, що дані зберігаються в SQLite.
2. **0:45–1:45.** Створіть категорію «Інструменти». Додайте «Ліхтарик», місце «Верхня шухляда», короткий опис і фото з галереї.
3. **1:45–2:30.** У каталозі введіть «ЛІХ» і виберіть «Інструменти». Відкрийте результат та змініть місце зберігання.
4. **2:30–3:30.** Відкрийте «Інструменти» й покажіть пояснення блокування видалення. Закрийте Expo Go, відкрийте той самий проєкт і перевірте запис із фото.
5. **3:30–4:30.** Видаліть річ із підтвердженням, а потім порожню категорію. Покажіть актуальні лічильники та результати `npm test`.

## Зберігання та розгортання

Після завантаження JavaScript застосунок використовує локальну БД і файлову систему. Перший запуск із Metro та повторне завантаження коду в Expo Go можуть потребувати з’єднання з комп’ютером або тунелем. Дані прив’язані до сховища проєкту в Expo Go. Після видалення Expo Go чи очищення його даних каталог може бути втрачений. У проєкті немає хмарної синхронізації або експорту бази.

Expo Go відкриває код всередині своєї оболонки. Для окремого встановлюваного застосунку можна з Windows налаштувати EAS Build, створити збірку iOS, завантажити її в App Store Connect та розповсюдити через TestFlight. Для TestFlight потрібні участь в Apple Developer Program і підписана збірка, а для зовнішніх тестувальників може знадобитися перевірка Apple. Цей шлях необов’язковий для захисту. [EAS Build](https://docs.expo.dev/build/setup/) · [TestFlight](https://developer.apple.com/testflight/)

Вимоги та діаграми описані в [docs/requirements.md](docs/requirements.md) і [docs/architecture.md](docs/architecture.md). Текст за структурою шаблону ХНТУ є в [пояснювальній записці](docs/coursework.md). Перелік реальних скриншотів наведено в [інструкції до знімків](docs/screenshots/README.md).
